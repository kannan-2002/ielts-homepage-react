# IELTS Institute Home Page  
A modern and responsive **React.js** landing page for a fictional IELTS Institute.  
This project showcases a clean UI with a professional design, highlighting key features of an IELTS training center.

---

## 🚀 Features
- **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.  
- **Modern UI** – Clean layout with Tailwind CSS for fast styling.  
- **Sections Included**:  
  - **Navbar** – Logo & navigation links.  
  - **Hero Section** – Headline, sub-text, call-to-action button, and banner image.  
  - **Feature Cards** – Highlights services like Speaking Practice, Mock Tests, and AI Band Score.  
  - **Student Testimonials** – 2–3 short reviews for credibility.  
  - **Footer** – Basic links and contact info.

---

## 🛠️ Tech Stack
- **React.js** – Component-based UI development.
- **Tailwind CSS** – For styling and responsiveness.

2. **Install dependencies**
   ```bash

3. **Run the development server**
